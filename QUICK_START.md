## 📋 Simple 3-Step Deployment

### Step 1: Rename Files
```bash
mv index-premium.html index.html
mv styles-premium.css styles.css
mv script-premium.js script.js
mv vercel-premium.json vercel.json
```

### Step 2: Push to GitHub
```bash
git init
git add .
git commit -m "BLACKSKY2099 Website"
git remote add origin https://github.com/BLACKSKY2099/website.git
git push -u origin main
```

### Step 3: Deploy on Vercel
1. Visit [vercel.com](https://vercel.com)
2. Click "New Project"
3. Select your GitHub repository
4. Click "Deploy"
5. Done! 🎉

**Your live site:** `https://[your-project].vercel.app`
